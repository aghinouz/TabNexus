# 页脉 TabNexus

## 让浏览不再是一堆网页，而是一张可以回溯的信息脉络。

当标签逐渐增加到几十、几百甚至上千之后，真正困扰你的往往不再只是“标签太多”，而是：

> 这个页面是从哪里来的？
> 我之前是沿着什么路径找到它的？
> 过几天，我还能从上百个网页中重新找回它吗？

浏览器标签栏告诉你：**你现在打开了什么。**
浏览器历史记录告诉你：**你曾经访问过什么。**
而页脉（TabNexus）更关注：**你是如何从一个页面，走到另一个页面的。**

**页脉** 尝试将零散的标签页重塑为一个**可理解、可搜索、可保存与可回溯**的独立浏览工作空间，让你重新找回自己的浏览路径。

## 🌲 一、 理清脉络：看见网页之间的关系

真实的网页探索很少是一条直线，而是在不断的搜索、跳转与分支中展开。页脉致力于帮你还原这一过程。

* **浏览关系树**：自动记录标签页之间的父子派生关系。你看到的不再是孤立的网页，而是清晰的探索足迹（支持直接提取或导出特定分支）。
* **标签级浏览轨迹**：每一个标签都拥有自己独立的“来路”。长按界面左上角的前进/后退按钮，即可唤出该标签专属的历史轨迹，无需在庞大的全局历史中大海捞针。

## 🔍 二、 极速找回：从海量信息中精准定位

当积累了数百个网页，你需要一套比肉眼查找更高效的过滤系统。

* **自动提取关键词**：你不需要手动整理标签，页脉会告诉你这一堆网页都在讨论什么。
* **正则与多维搜索**：支持对标题和 URL 使用正则表达式进行高阶精确匹配，并可一键按“最近访问时间”重新排序。

## 💾 三、 沉淀与掌控：将浏览升格为工作流

你的浏览心血，不应被局限在当前的浏览器窗口内。页脉提供了一整套掌控复杂浏览局面的工具。

* **结构化导入与导出**：将搜索匹配的标签（含父子层级关系）导出为 JSON 备份。重新导入时采用分块静默加载，避免一次性创建大量标签页导致瞬时资源占用。
* **受限网页保护**：针对浏览器安全策略禁止直接打开的本地文件（`file:///`）或内部设置页，页脉会自动生成带有 `[受限]` 标记的安全占位页，确保你的浏览结构绝不静默丢失。
* **独立窗口与全能批处理**：支持一键脱离为主浏览器之外的独立管理窗口（双屏利器）；提供一键定位、固定、复制链接、批量清理未固定项等操作，在复杂环境中维持基本秩序。

## ⭐ 四、功能兼容：让体验更沉浸

在浏览器的基础功能上深耕并扎根。

* **无缝融入原生分组**：深度适配浏览器原生标签组（Tab Groups），提供极简的无箭头折叠交互，且**与浏览器原生折叠状态保持双向实时同步**。
* **细微功能也值得关注**: 在 Firefox 中，以柔和的渐变背景色直观区分不同 Container（容器）边界。

## 👥 为复杂浏览而生

如果你经常需要同时维护几十上百个标签，且你的浏览方式通常是：

> 搜索 → 跳转 → 比较 → 引用 → 延伸 → 再搜索 → 再回溯

那么页脉就是为你设计的。它极其适合：

* **程序员**：穿梭于文档、GitHub、Issue 与代码库，随时回溯查阅线索。
* **研究人员与学生**：长期保留大量参考页面，追踪论文与资料的来源关系。
* **内容创作者与资料搜集者**：搜集繁杂素材，并在几周后仍能迅速找回。
* **重度信息检索用户**: 会围绕一个问题不断开几十个甚至上百个网页。

## 🛡️ 本地优先，数据归你

页脉坚持 **本地优先** 的设计理念：

* **注重隐私**：本地优先，数据留在你的浏览器中，不上传浏览记录。
* **极致性能**：底层算法专为成百上千的标签页场景优化，丝滑流畅。
* **原生体验**：自适应中文/英文双语界面与系统深色/浅色模式。

## **页脉 TabNexus** —— 不只是另一个标签栏

它是为你理清信息碎片的浏览工作空间。
